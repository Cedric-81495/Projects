# Changes applied — 2026-08-18

Everything below is already in this zip. Two things still need doing by hand:
run the new migration, and set one environment variable when Jake sends it.

---

## Do this after unzipping

**1. Install the new dev dependency**

```
npm install
```

Adds `@types/qrcode`, which `/sign` needs to type-check. Without it `next build`
fails on TS7016.

**2. Run the new migration**

Supabase → SQL Editor → paste `supabase/migrations/0008_leads.sql` → Run.

**3. When Jake sends the webhook URL**

Vercel → Environment Variables → **Preview and Production both**:

```
GHL_WEBHOOK_URL=https://services.leadconnectorhq.com/hooks/...
```

Server-only. Never prefix it with `NEXT_PUBLIC_`. Until it is set the forward
no-ops, leads accumulate as `pending`, and the cron drains them automatically
once it exists — so nothing is lost by deploying before he replies.

## Verify after deploying

```
npx tsc --noEmit
```

Then confirm the endpoint is wired:

```
curl -X POST https://gwop-university-develop.vercel.app/api/lead \
  -H "content-type: application/json" -d "{}"
```

A **400 validation error** is the correct answer — it proves the route, the
handler wrapper, the rate limiter and the Zod schema are all in place. A 404
means the file is not where Next expects it.
