Step 3 — Log in to Stripe CLI
powershell
stripe login

This opens a browser window asking you to authorize the CLI with your Stripe account. Click Allow access. You'll see Done! The Stripe CLI is configured in the terminal.

Step 4 — Start the webhook listener

Make sure your Express server is running first (npm run dev in the server/ folder), then in a separate terminal:

powershell
stripe listen --forward-to localhost:4000/api/webhooks/stripe

The CLI will print something like this:

> Ready! Your webhook signing secret is whsec_a1b2c3d4e5f6...

That whsec_... value is your STRIPE_WEBHOOK_SECRET — copy it and paste into server/.env:

env
STRIPE_WEBHOOK_SECRET=whsec_a1b2c3d4e5f6...

Restart the server after updating .env:

powershell
# stop server with Ctrl+C, then:
npm run dev
Step 5 — Verify it's working

The Stripe CLI terminal will show events arriving in real time when you test checkout. You should see lines like:

2026-07-25 --> checkout.session.completed [evt_xxx]
2026-07-25 <-- [200] POST http://localhost:4000/api/webhooks/stripe

That 200 means your server received and handled the event correctly.
