## History

A previous implementation of this project lived at this path and was removed
in favour of a fresh start. It is still recoverable from git history if any of
it is worth referencing:

```sh

```

That version was a React + TypeScript client (Vite, Tailwind, React Router)
with an Express + TypeScript API (Mongoose, JWT cookie auth, Braintree
payments, Supabase storage). It built and typechecked cleanly at the time it
was removed.
